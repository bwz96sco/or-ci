# Design

## Boundary

This task updates note-vault experiment generators, not the OR-CI runtime. The source of truth remains the frozen addendum plus generated bundle scripts under `experiments/packs/or-ci-labeling-operations-2026-05-26/`.

## Artifact Contract

Each generated rater bundle will contain:

- existing packet files;
- existing blank rater label CSVs;
- existing safe manifest and summary;
- new `RATER-INSTRUCTIONS.md` generated by the bundle builder.

The instruction card is intentionally generic and packet-ID based. It must not mention internal case IDs, coordinator maps, raw evidence roots, or prior review decisions.

## Implementation Shape

- Add a small shared instruction-card helper or equivalent local helper in the labeling operations scripts.
- Wire the card into the four bundle builders:
  - `build_cold_protocol_rater_bundle.py`
  - `build_capstone_rater_bundle.py`
  - `build_phase2_50case_rater_bundle.py`
  - `build_nl4opt_rater_bundle.py`
- Include the instruction card in each bundle summary/readme where useful.
- Extend bundle validation so missing/stale cards are caught.

## Compatibility

Existing label CSV schemas and packet files remain unchanged. The card is additive, so downstream intake gates should not need schema changes.
